# 图像生成工作流程

## 核心原则

多模态模型（如 Nano Banana 2 / Gemini 3.1 Flash Image）对语义理解能力强，使用**符合语法顺序的正常句子**，而非关键词堆砌。

## 何时使用此 Skill

- 使用 `mcp__image__generate_image` 工具进行图像生成
- 基于参考图进行风格迁移
- 编辑图像特定元素（如修改颜色、物体、姿态）
- 扩展图像（如半身像扩展为全身像）
- 管理生成的图像文件
- 需要保持参考图绘画风格和质感

## 文件管理

### 默认输出路径

**所有生成的图像应保存到：**
```
D:/AgentWorkspace/files/生成图/
```

### 文件命名规范

**推荐命名格式：**
```
[项目名]_[比例]_[版本].png
```

**示例：**
- `ancient_lady_fullbody_9to16_v3.png` - 古装少女全身图 9:16 比例第3版
- `portrait_4to5_final.png` - 肖像 4:5 最终版
- `landscape_16to9_4K.png` - 风景 16:9 4K 版

### 文件组织

**按项目分类：**
```
files/生成图/
├── 古装少女/
│   ├── ancient_lady_9to16_v1.png
│   └── ancient_lady_9to16_v2.png
├── 风景/
│   └── landscape_16to9.png
└── 人物/
    └── portrait_4to5.png
```

### 批量移动文件

**将生成的图片移动到指定文件夹：**
```bash
# 移动所有生成的 PNG 文件
mv D:/AgentWorkspace/files/*.png "D:/AgentWorkspace/files/生成图/"

# 按项目移动
mv D:/AgentWorkspace/files/ancient_lady*.png "D:/AgentWorkspace/files/生成图/古装少女/"
```

### 文件大小参考

**Discord 发送限制：**
- 普通服务器：25 MB
- Nitro：500 MB

**不同分辨率的文件大小：**
- 1K：约 1.6-2 MB
- 2K：约 5-8 MB
- 4K：约 20-22 MB（可能超过 Discord 限制）

## 提示词编写指南

### 基本结构

```
采用参考图[参考图名称]的绘画风格，[操作指令]，[其他要求]
```

### 四大要点

#### 1. 使用正常句子
- ✅ **正确**：`采用参考图酒瓶的绘画风格，生成一个中式灯笼，并采用白色背景`
- ❌ **错误**：`一个中式灯笼，白色背景，采用参考图酒瓶的绘画风格`

#### 2. 明确参考风格
- ✅ **正确**：必须明确说明"采用参考图xx的绘画风格"
- ❌ **错误**：详细描述风格、画法、质感（会干扰 AI 学习）

#### 3. 避免过度描述风格
❌ **错误示例**：
```
传统中式灯笼，手绘插画风格，粗犷笔触，古风东方奇幻风格，粗陶哑光质感，白色背景
```
这种写法会：
- 干扰 AI 学习参考图的真实风格
- 生成不一致的风格
- 可能导致元素过多（如生成 6 个灯笼而非 1 个）

#### 4. 详细描述画面内容
- ✅ **正确**：对想要的内容可以详细描述（人物姿态、服饰、道具、背景、色彩等）
- ❌ **错误**：内容描述过于简略

#### 5. 明确修改范围（编辑场景）
- 使用"其他保持不变"来限制修改范围
- ✅ **正确**：`采用参考图风霜的画面风格，把人物的衣服改为黑色，其他保持不变`

## 常见场景

### 场景 1：风格迁移

基于参考图风格生成新内容。

**提示词模板**：
```
采用参考图[参考图名称]的绘画风格，生成[目标内容描述]，[其他要求如背景、比例等]
```

**示例**：
```
采用参考图酒瓶的绘画风格，生成一个中式灯笼，并采用白色背景
```

### 场景 2：图像编辑

修改图像的特定元素，保持其他部分不变。

**提示词模板**：
```
采用参考图[参考图名称]的画面风格，[修改具体元素]，其他保持不变
```

**示例**：
```
采用参考图风霜的画面风格，把人物的衣服改为黑色，其他保持不变
```

**常用修改指令**：
- 修改颜色：`把[元素]改为[颜色]`
- 添加元素：`在[位置]添加[元素]`
- 删除元素：`删除[元素]`
- 改变姿态：`把人物改为[姿态描述]`

### 场景 3：扩图（Outpainting）

将半身像扩展为完整全身图，或扩展画面范围。

**提示词模板**：
```
采用参考图[参考图名称]的绘画风格，将半身像扩展为完整的全身图像，保持[具体细节]，补充完整的身体和背景，保持[风格特征]
```

**示例**：
```
采用参考图上半身的绘画风格，将半身像扩展为完整的全身图像，保持人物回眸姿态、服饰、发型、团扇等所有细节，补充完整的身体和背景，保持日系厚涂风格和暖色调
```

## 效果对比案例

### 案例 1：生成灯笼

**错误写法**（关键词堆砌 + 过度描述风格）：
```
传统中式灯笼，手绘插画风格，粗犷笔触，古风东方奇幻风格，粗陶哑光质感，白色背景
```
**结果**：生成 6 个复杂国潮灯笼，风格不一致

**正确写法**（正常句子 + 明确参考风格）：
```
采用参考图酒瓶的绘画风格，生成一个中式灯笼，并采用白色背景
```
**结果**：生成单个灯笼，完美继承酒瓶的手绘、粗犷、古风风格 ✅

### 案例 2：修改衣服颜色

**正确写法**：
```
采用参考图风霜的画面风格，把人物的衣服改为黑色，其他保持不变
```
**结果**：成功将白衣改为黑衣，其他元素（窗台、明月、雪花、竹林、酒坛、提灯、书卷）全部保持一致 ✅

## 高级技巧

### 组合操作
可以在一次提示中组合多个操作：
```
采用参考图[名称]的画面风格，把[元素A]改为[A2]，把[元素B]改为[B2]，其他保持不变
```

### 保持特定元素
在扩图或复杂编辑时，列出需要保持的具体细节：
```
保持人物回眸姿态、服饰、发型、团扇等所有细节
```

### 比例和分辨率

**支持的 Aspect Ratio（14 个）：**

**标准比例：**
- `1:1` - 正方形（社交媒体头像、Instagram）
- `16:9` - 宽屏（YouTube 缩略图、演示文稿）
- `4:3` - 传统显示器、传统摄影
- `9:16` - 手机竖屏（TikTok、Instagram Stories）
- `2:3` - 竖屏照片
- `3:2` - 横屏照片
- `4:5` - 肖像
- `5:4` - 传统显示器
- `21:9` - 超宽屏

**超宽/超高比例（Nano Banana 2 新增）：**
- `1:4` - 超高竖版（长海报、信息图表）
- `4:1` - 超宽横版（全景图、横幅）
- `1:8` - 极端超高竖版（超长信息图）
- `8:1` - 极端超宽横版（360° 全景）

**分辨率选项：**
- `1K` - 标准清晰度（约 1-2 MB）
- `2K` - 高清晰度（约 5-8 MB）
- `4K` - 超高清（约 20-22 MB，可能超过 Discord 限制）

### 模型选择

**当前默认模型：Nano Banana 2**
- 模型名称：`gemini-3.1-flash-image-preview`
- 发布时间：2026 年 2 月 26 日
- 特点：比 Flash 2.5 快 3-5 倍，质量接近 Pro 级别

**模型切换：**
- 默认使用 Flash 模型（Nano Banana 2）
- 设置 `pro=true` 可切换到 Pro 模型（gemini-3-pro-image-preview）
- Pro 模型质量更高但速度较慢

**模型配置（通过 .env 文件）：**
```bash
# Flash 模型（默认）
GEMINI_FLASH_MODEL=gemini-3.1-flash-image-preview

# Pro 模型
GEMINI_PRO_MODEL=gemini-3-pro-image-preview
```

**配置文件位置：**
- `D:/AgentWorkspace/image-mcp/.env`

**修改模型后需要重启 MCP 服务器。**

## 工具使用指南

### generate_image 工具参数

**必需参数：**
- `prompt`（字符串）：图像描述

**可选参数：**
- `output_path`（字符串）：输出文件路径
  - 如果不提供，自动保存到 `files/生成图/`
  - 如果提供完整路径，使用指定路径
- `filename`（字符串）：文件名（不含路径）
  - 示例：`my_image.png`
  - 与 `output_path` 二选一，推荐使用 `filename`
- `reference_images`（数组）：参考图路径列表
  - 最多 14 张图片
  - 用于 img2img 模式
- `aspect_ratio`（字符串）：画幅比例
  - 支持 14 种比例（见上文）
  - 默认：`1:1`
- `resolution`（字符串）：分辨率
  - `1K`、`2K`、`4K`
  - 默认：`1K`
- `pro`（布尔）：是否使用 Pro 模型
  - `true` 或 `false`
  - 默认：`false`

### 使用示例

**示例 1：使用默认路径（推荐）**
```python
generate_image(
    prompt="生成一个简笔画风格的红色苹果",
    filename="apple.png",
    aspect_ratio="1:1",
    resolution="1K"
)
# 保存到：files/生成图/apple.png
```

**示例 2：使用参考图**
```python
generate_image(
    prompt="采用参考图的绘画风格，生成一个中式灯笼",
    filename="lantern.png",
    reference_images=["path/to/reference.png"],
    aspect_ratio="3:4"
)
# 保存到：files/生成图/lantern.png
```

**示例 3：自定义路径**
```python
generate_image(
    prompt="生成一个风景图",
    output_path="D:/custom/path/landscape.png",
    aspect_ratio="16:9",
    resolution="2K"
)
# 保存到：D:/custom/path/landscape.png
```

**示例 4：使用 Pro 模型**
```python
generate_image(
    prompt="生成一个高质量的人物肖像",
    filename="portrait.png",
    pro=True,  # 使用 Pro 模型
    resolution="4K"
)
# 保存到：files/生成图/portrait.png
```

**示例 5：多参考图（最多 14 张）**
```python
generate_image(
    prompt="结合两张参考图的风格，生成一个古风人物",
    filename="character.png",
    reference_images=["ref1.png", "ref2.png"],
    aspect_ratio="9:16"
)
# 保存到：files/生成图/character.png
```

## 总结

1. **用正常句子**：符合语法顺序，语义清晰
2. **明确参考风格**："采用参考图xx的绘画风格"
3. **不描述风格**：让 AI 自己从参考图学习
4. **内容可详细**：想要什么可以详细说
5. **明确修改范围**：编辑时说明"其他保持不变"
